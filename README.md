# 🚀 Modern & Interactive Engineering Portfolio

A premium, high-performance, and fully responsive software engineering portfolio designed to showcase technical skills, academic milestones, and production-grade full-stack applications. Featuring an ultra-modern dark glassmorphic UI, dynamic full-screen glowing gradients, scroll-linked reveal mechanics, and an interactive fluid cursor-tracking system.

## ✨ Key Visual & Technical Features

- **Premium Dark Aesthetics & Glow Mapping:** Built using multi-layered radial background gradients coupled with text-glow shadowing effects for sharp, high-contrast readability.
- **Modern Glassmorphism:** Card containers use translucent backgrounds with low-opacity borders (`rgba`), heavy saturation layers, and advanced CSS backdrop filtering to simulate premium frosted glass.
- **Interactive Mouse Cursor Follower:** Features a dynamic, hardware-accelerated cursor ring that captures mouse coordinates in real time with custom easing transitions when hovering over interactive nodes.
- **Scroll-Linked Animations:** Leverages a lightweight `IntersectionObserver` instance to seamlessly reveal page sections as they enter the browser viewport, completely removing any raw layout shifts.
- **Custom Vector Scrollbar:** Replaces non-standard native browser tracks with unified slate and neon-blue accents matching the overarching theme.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Core:** HTML5, CSS3 (Modern Variables, Flexbox, Keyframe Animations, Paged Media Adaptations)
- **Interactivity Engine:** Vanilla JavaScript (ES6+, DOM Manipulation, asynchronous event listening, Intersection Observer API)
- **Typography & Icons:** Google Fonts (Poppins), FontAwesome v6 Icons
